# Фото в PDF — Android

Простое приложение: выберите фотографии, поменяйте порядок перетаскиванием
или стрелками, обрежьте и поверните снимки, настройте фильтры, страницу и
поля. Предпросмотр показывает настоящий PDF; синяя разметка полей видна только
в предпросмотре. Сохранение выполняется через системное окно Android.

## Возможности

- Выбор только указанных пользователем изображений в системном Photo Picker
  (или системном окне выбора файлов на Android 9–12), без доступа ко всей галерее.
- До 50 фотографий за один документ, по одной на страницу.
- Ручная обрезка, поворот с немедленным предпросмотром, цвет, чёрно-белый,
  контрастный документ и «Эффект скана · цветной».
- A4, Letter или страница по пропорциям фото; поля 0, 14, 32 PDF-пункта.
- Цветной эффект скана слегка осветляет фон и повышает контраст, без пороговой
  чёрно-белой обработки и дополнительного уменьшения разрешения.
- Экспорт ограничивает длинную сторону изображения до 3508 пикселей, чтобы
  избежать исчерпания памяти на телефонах. Это не исходное разрешение, если
  оригинальная фотография крупнее.

## Безопасность и приватность

- Приложение не запрашивает разрешение INTERNET или доступ ко всей галерее,
  не содержит SDK рекламы, аналитики и сторонних зависимостей приложения.
- Фотографии и временные PDF остаются локально в приложении; после сохранения
  или закрытия предпросмотра временный файл удаляется, а оставшийся после
  аварийного завершения кэш очищается при следующем запуске.
- Резервное копирование данных приложения отключено. Открытие уже сохранённого
  PDF во внешней программе происходит только по нажатию «Открыть»: выбранный
  просмотрщик получает доступ к этому PDF.
- Сборочный workflow ограничен правом read к репозиторию; внешние Actions
  закреплены по SHA, скачиваемый Gradle проверяется по официальному SHA-256,
  артефакт содержит APK и файл с контрольной суммой.
- Это debug APK со временной подписью сборочной машины. Для регулярного выпуска
  и обновлений необходим отдельный постоянный ключ подписи, хранящийся вне
  публичного репозитория. Ни один аудит исходников не гарантирует абсолютную
  защиту устройства: устанавливайте APK только из сборок своего репозитория
  и обновляйте Android.

## Сборка

GitHub → **Actions** → последняя успешная **Build Android APK** → раздел
**Artifacts** → `photo-pdf-debug-apk` → распаковать и установить
`app-debug.apk` на Android 9 или новее. На Mac можно собрать локально с
Android SDK 35 и JDK 17: `chmod +x gradlew && ./gradlew assembleDebug`.
Первый запуск скачает Gradle 8.9 и проверит контрольную сумму архива.

## Ограничения

- «Эффект скана» не исправляет перспективу и не распознаёт текст (OCR).
- При множестве больших фото PDF может быть большим и обработка займёт время.
- После принудительного закрытия приложения список выбранных страниц исчезнет.
