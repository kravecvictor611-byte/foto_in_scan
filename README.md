# Фото в PDF — Android

Минимальное приложение без регистрации, рекламы, сервера и водяного знака.
Выберите фотографии, поменяйте их порядок, нажмите на снимок для обрезки,
поворота и фильтра, укажите страницу и поля, сохраните PDF через системное
окно Android. Фотографии не загружаются в интернет.

## Как открыть на Mac

1. Установите Android Studio с Android SDK 35 и JDK 17.
2. Откройте папку `PhotoPdf` через **File → Open**.
3. При необходимости выберите в настройках Gradle JDK 17.
4. Запустите конфигурацию **app** на телефоне Android 9+ (API 28+) или эмуляторе.

Из терминала Mac: `chmod +x gradlew && ./gradlew assembleDebug`.
Первый запуск скачает Gradle 8.9 и Android Gradle Plugin из официальных
репозиториев. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Что есть в версии 1

- Выбор до 50 фотографий через системный выбор фото на Android 13+; на более
  ранних версиях — через системный выбор файлов.
- Одна фотография на страницу; смена порядка кнопками ↑ и ↓, удаление.
- Обрезка перетаскиванием углов или всей рамки, поворот на 90°.
- Цвет, оттенки серого, контрастный чёрно-белый режим. Фильтр виден в редакторе.
- A4, Letter или лист по пропорциям фотографии; альбомная ориентация автоматически.
- Поля 0, 14 или 32 PDF-пункта. Фото вписывается целиком без искажений.
- Создание PDF на устройстве и выбор места сохранения; нет водяного знака.

## Ограничения и следующие улучшения

- Для полного аналога сканера нужны автоматическое обнаружение границ,
  исправление перспективы и OCR. Сейчас рамка прямоугольная и настраивается вручную.
- Размер PDF при многих фотографиях может быть большим; экспорт ограничивает
  длинную сторону декодированного фото до 2600 пикселей.
- После принудительного закрытия приложения текущий список страниц не сохраняется.
- В редакторе рамка обрезки показана до поворота; итоговый результат виден
  в миниатюре после подтверждения.
- Проект подготовлен как исходный код. Здесь нет Android SDK, поэтому сборка
  APK и запуск на устройстве в этой среде не проводились.

## Монетизация

Бесплатное приложение может работать вообще без рекламы и водяного знака.
Если позже понадобится доход, можно добавить необязательное платное улучшение,
но это отдельное решение после проверки спроса.
